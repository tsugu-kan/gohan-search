# ごはんサーチ

Google マップと YouTube の情報をまとめて見られる、飲食店検索アプリです。
iPhone の Safari から「ホーム画面に追加」すると、普通のアプリのように使えます(Mac 不要)。

## できること

- **周辺**:現在地から 500m〜5km 以内の飲食店・カフェを表示(人気順/評価順/近い順)
- **料理で探す**:「ラーメン」「串カツ」など料理名で、範囲内の人気店を表示
- **お店の詳細**:写真・評価・住所・電話・公式サイト・営業時間・Google の口コミ、店名+地域名で探した YouTube 動画、X・Instagram・YouTube の検索結果へのリンク

「人気順」は `評価 × log10(口コミ数 + 1)` で計算しています(評価が高く、口コミも多い店が上)。

ファイルは3つだけです:`index.html`(アプリ本体)、`manifest.webmanifest`、`icon-512.png`

## 公開と設定の手順(すべて iPhone でできます)

### 1. GitHub に置いて公開する

1. Safari で github.com にログイン
2. 右上「+」→「New repository」
   - Repository name:`gohan-search`
   - **Public** を選んで「Create repository」
3. 「uploading an existing file」をタップし、3つのファイル(`index.html`・`manifest.webmanifest`・`icon-512.png`)を選んで「Commit changes」
   - ファイルアプリで zip をタップすると解凍できます
4. リポジトリの「Settings」→ 左メニュー「Pages」
   - Branch:`main`、フォルダ:`/ (root)` → 「Save」
5. 1〜2分待つと次の URL で開けるようになります
   **https://tsugu-kan.github.io/gohan-search/**

### 2. Google Cloud で API キーを作る

1. Safari で https://console.cloud.google.com/ にログインし、新しいプロジェクトを作成
2. 「お支払い」で請求先アカウントを設定(Google マップの API に必須)
3. 「API とサービス」→「ライブラリ」で次の3つを**有効化**
   - **Maps JavaScript API**
   - **Places API (New)**
   - **YouTube Data API v3**
4. 「認証情報」→「認証情報を作成」→「API キー」
5. 作ったキーを開いて、**必ず制限をかけます**(他人に悪用されないため)
   - アプリケーションの制限:**ウェブサイト** → `https://tsugu-kan.github.io/*` を追加
   - API の制限:上の3つの API だけを選択
6. 「お支払い」→「予算とアラート」で少額(例:月1,000円)の予算アラートを設定しておくと安心です

### 3. iPhone のホーム画面に追加する

1. Safari で https://tsugu-kan.github.io/gohan-search/ を開く
2. 共有ボタン(□↑)→「ホーム画面に追加」→「追加」
3. **ホーム画面のアイコンから** アプリを開く
4. 「設定」タブに API キーを貼り付けて「保存して再読み込み」
5. 位置情報の許可を聞かれたら「許可」

> ホーム画面のアプリと Safari は保存場所が別なので、キーは必ずホーム画面から開いた状態で登録してください。

## API キーの安全性について

- キーはコードに書かず、**iPhone の中(アプリの保存領域)だけ** に保存されます。GitHub には公開されません。
- それでもアプリが通信するときにキーは使われるため、手順2-5の「ウェブサイトの制限」を必ずかけてください。これで他のサイトからはキーが使えなくなります。

## 料金・利用上限の目安

- **Google マップ(Places API など)**:月ごとの無料枠があり、超えると従量課金です。個人で使う程度なら無料枠に収まることが多いですが、料金は変わることがあるので Google Maps Platform の料金ページを確認してください。お店の「詳細」画面(口コミ・営業時間)は単価が高めです。
- **YouTube Data API**:無料。ただし1日 10,000 ユニットまでで、動画検索は1回100ユニット → **1日あたり約100回** が上限です。同じ検索は12時間保存して使い回しています。

## カスタマイズ

料理名のボタン(ラーメン、焼肉…)は `index.html` の `const PRESETS = [...]` を書き換えると変えられます。GitHub 上でファイルを開き、鉛筆マークから直接編集できます。
